# 📊 Sales Data Analysis with Pandas

## 📌 Project Overview

This project focuses on analyzing a sample sales dataset using **Python and Pandas** to extract meaningful business insights. The analysis includes calculating key sales metrics, identifying top-selling products, and summarizing sales performance by category, region, and time period.

This project was completed as part of **Task 2 of my CodeOrbit internship** to gain practical experience in data analysis and data manipulation.

## 🎯 Objectives

- Analyze and process sales data using Pandas.
- Calculate total sales and average order value.
- Identify top-selling products.
- Group and summarize sales by region, category, and time period.
- Prepare a short report highlighting key findings.

## 🛠️ Tools and Technologies

- **Python** – Programming language for data analysis.
- **Pandas** – Data manipulation, grouping, and aggregation.
- **NumPy** – Numerical operations.
- **Jupyter Notebook** – Interactive environment for writing and executing code.

### 1. Data Loading and Exploration

### 2. Sales Metrics
- Calculated total sales.

## 💻 Installation and Usage

### Prerequisites
Install Python and Jupyter Notebook on your system.

### Install Required Libraries

```bash
pip install pandas numpy jupyter
```

### Run the Project

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Sales-Data-Analysis.git
```

2. Navigate to the project folder:

```bash
cd Sales-Data-Analysis
```

3. Start Jupyter Notebook:

```bash
VS code
```

4. Open `sales_analysis.ipynb` and run the cells in order.

**Note:** Ensure that `sales_data.csv` is available in the project folder before running the notebook.
